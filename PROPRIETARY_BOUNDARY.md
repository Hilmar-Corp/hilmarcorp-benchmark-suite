# Proprietary boundary

The public repository excludes:

- Nostra model logic;
- model features, weights and parameters;
- probability outputs;
- daily Nostra positions;
- daily Nostra returns;
- daily Nostra equity and drawdown series;
- turnover and transaction-cost traces;
- private data transformations;
- production infrastructure and credentials;
- private source paths;
- serialized models;
- internal research traces;
- the website chart data artifact.

The public repository may include:

- public benchmark source code;
- tests and validation controls;
- aggregate Nostra metrics;
- daily curves for public reference strategies;
- methodology metadata;
- cryptographic manifests;
- a SHA-256 commitment to the retained private evaluation artifact.

No Nostra time series is distributed through GitHub.
