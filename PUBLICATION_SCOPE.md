# Publication scope

## Public GitHub material

The repository distributes:

- benchmark and accounting code;
- public reference strategies;
- tests and quality controls;
- public baseline equity and drawdown curves;
- aggregate benchmark metrics;
- methodology and integrity metadata.

## Nostra disclosure

Nostra AI remains proprietary.

GitHub contains aggregate Nostra metrics and a SHA-256 commitment only. It
contains no Nostra time series or execution trace.

## Website disclosure

A separate website process may display delayed daily equity points. The
website artifact is not included in GitHub and must enforce a minimum
fourteen-day delay.
