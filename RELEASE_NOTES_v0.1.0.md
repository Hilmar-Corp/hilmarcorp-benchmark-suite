# HilmarCorp Benchmark Suite v0.1.0

This release establishes the first institutionally hardened public benchmark
surface.

## Controls

- public benchmark source code under Apache-2.0;
- controlled performance artifacts under separate reserved rights;
- no Nostra time series or execution trace in GitHub;
- Nostra aggregate results classified as artifact-verified;
- explicit Nostra governed exposure range from -10% to +100%;
- public benchmark exposure range from 0% to 100%;
- deterministic benchmark replay from the committed public artifact;
- exact Python 3.13 dependency constraints;
- CI across Python 3.11, 3.12 and 3.13 on Ubuntu and macOS;
- branch-aware coverage threshold of 90%;
- SHA-256 manifests and tamper detection;
- dependency vulnerability audit;
- CycloneDX dependency SBOM;
- CodeQL;
- immutable GitHub Actions references;
- versioned controlled artifacts.

This release does not constitute independent external validation of Nostra AI.
