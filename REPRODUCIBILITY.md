# Reproducibility

Public reference strategies are code-reproducible from this repository.

Nostra AI is artifact-verified rather than open-source. Every controlled
release records a SHA-256 commitment to the retained private evaluation
artifact.

The repository applies deterministic accounting tests, execution-lag tests,
anti-look-ahead controls, branch coverage, release manifests, SHA-256
verification and automated publication-boundary checks.

This technical framework does not constitute independent external validation
or an external audit.
